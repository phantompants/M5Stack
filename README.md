# M5Stack

Reusable code, utilities, and base configurations across multiple M5Stack devices (`jp226prints` / `github@jp226prints.au`).

## Cardputer Zero Apps

- [`Cardputer-Zero/JP226-GPS-IMU-Logger-CP0`](Cardputer-Zero/JP226-GPS-IMU-Logger-CP0/README.md) — GPS/IMU telemetry logger, waypoints, vehicle setup, and basic OBD scan for CardputerZero.
- [`Cardputer-Zero/JP226-OBDii-Scanner-CP0`](Cardputer-Zero/JP226-OBDii-Scanner-CP0/README.md) — Read-only OBD-II scanner (USB / Wi-Fi / BLE) with live monitoring and compatibility profiling for `JP226-GPS-IMU-Logger` and `EV-Sound-Emulator` (CardputerZero & ADV).
